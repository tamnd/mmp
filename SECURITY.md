# Security

This repository holds text, data and the workflow that deploys the site. To report a security problem, use the private vulnerability report of GitHub on this repository. Do not open a public issue.

A report about the deploy workflow, the secrets or the content of the site gets an answer in seven days.

A finding of the audit of AxiomMath/MMP is not a security problem of this repository. A finding of severity 1 or 2 stays private for 30 days, so that the authors can answer (spec 14.4). Send it with the private vulnerability report. Do not open a public issue for it.
